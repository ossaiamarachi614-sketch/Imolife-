# IMO LIFE

A mobile-first browser life simulator set in Owerri, Imo State.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included
- React + Vite + Tailwind directives + Framer Motion + Lucide icons
- Mobile-first Home / Buy / Map / Phone navigation
- Persistent localStorage state for money, furniture, status bars, messages and transactions
- Owerri locations and mock online players
- Jobs, messaging, MeetImo, bank transfers, profiles, invites and apartment preview
- No backend required

## Note
The interface is an original implementation inspired by the supplied references. It does not copy proprietary source code or hidden assets from another game.
